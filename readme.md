# zhenxun-bottle · 真寻漂流瓶

把漂流瓶做进群聊：**扔瓶子、捡瓶子、评论、点赞**，全部免审核，扔出去立刻能被别人捡到。

> ⚠️ **这是二次开发的版本，不是原版。** 原版带一个 FastAPI Web 审核后台（瓶子需管理员在网页上审核后才能被捡到）；
> 本改版删掉了整个 Web 后台，改为免审核，并按 [zhenxun_bot](https://github.com/zhenxun-org/zhenxun_bot)
> 的插件规范重写为原生插件。

## 与原版的区别

| 方面                 | 原版                                                         | 本改版                                                       |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 目标平台             | 通用 NoneBot2 插件（pip 安装）                               | zhenxun_bot 原生插件（放入 `zhenxun/plugins/`）              |
| Web 审核后台         | 有（FastAPI + 登录鉴权 + Jinja2 模板）                       | **已删除**                                                   |
| 审核流程             | 扔瓶子进 `pending` 待审，管理员在网页过审后才能被捡          | **全部免审核**，直接进入可捡取状态；`pending` 表与 `state` 状态机已移除 |
| 配置方式             | 读 `.env`（`BOTTLE_ACCOUNT` 等环境变量）                     | 真寻配置系统（WebUI / `data/config.yaml` 可视化，改完**不用重启**） |
| 分群开关 / 权限 / CD | 无                                                           | 由真寻元数据驱动（`switch` 指令 / WebUI 可控）               |
| 帮助菜单             | 无                                                           | 归入「群内小游戏」分类，含指令说明与示例                     |
| 数据存储             | `nonebot-plugin-localstore` 目录                             | `data/web_bottle/`                                           |
| QQ-Markdown 通道     | 有（依赖 `127.0.0.1:8080` 的 Gensokyo 服务 + 未定义的 `玩家昵称接口`，开启即崩） | **已删除**                                                   |
| 硬编码               | 内置作者自己机器人的 QQ 号 `102050518` 与键盘模板 ID         | **已删除**                                                   |
| 依赖                 | 需要 `nonebot-plugin-localstore`、`itsdangerous`、`cryptography` 等 | 无需额外 pip 依赖（仅复用真寻已有依赖）                      |

## 环境要求

- [zhenxun_bot](https://github.com/zhenxun-org/zhenxun_bot)
- OneBot V11 适配器（唯一支持的适配器）
- 开发验证环境：Python 3.12 / nonebot2 2.5 / pydantic 2.13 / starlette 1.0

## 安装

本插件未发布到 PyPI，直接把目录放进真寻的插件目录即可：

```bash
git clone <本仓库地址> zhenxun/plugins/nonebot_plugin_web_bottle
```

目录结构应形如：

```
zhenxun_bot/
└── zhenxun/
    └── plugins/
        └── nonebot_plugin_web_bottle/
            ├── __init__.py     # 元数据 + 指令
            ├── bottle.py       # 数据层
            ├── config.py       # 配置访问器
            ├── data_deal.py    # sqlite 初始化
            └── to_msg.py       # 消息渲染
```

**重启 bot** 后生效。首次启动会自动在 `data/web_bottle/` 建库建表并在 `data/configs/plugins2config.yaml`
注册 9 个配置项。

> 若从旧版（带 `pending` 表的版本）升级：启动时会自动把 `pending` 中的瓶子并入 `approved` 再删除该表，
> 旧数据不会丢。已经是本改版的版本重复启动无副作用。

## 指令

| 指令                       | 别名         | 说明                                |
| -------------------------- | ------------ | ----------------------------------- |
| `丢瓶子 [图片/文本]`       | `扔瓶子`     | 扔一个漂流瓶进大海，支持文字 + 图片 |
| `捡瓶子`                   | `捡漂流瓶`   | 随机捞起一个漂流瓶                  |
| `查看漂流瓶 <编号>`        | —            | 查看指定漂流瓶                      |
| `评论漂流瓶 <编号> <内容>` | —            | 给漂流瓶留言（立即显示）            |
| `点赞漂流瓶 <编号>`        | —            | 给漂流瓶点赞（每人每瓶一次）        |
| `漂流瓶`                   | `漂流瓶菜单` | 查看帮助                            |

限制：图片最多 2 张、文本最多 1200 字符 / 9 行（均可在 WebUI 调整）；非文字/图片的消息会被拒绝并提示。
所有指令共用 **6 秒**插件级冷却。

## 配置项

在真寻 WebUI 的插件配置页或 `data/config.yaml` 中修改，**修改后无需重启**。

| 配置项                | 默认值     | 说明                                              |
| --------------------- | ---------- | ------------------------------------------------- |
| `MAX_BOTTLE_PIC`      | `2`        | 丢瓶子时允许附带的最大图片数量                    |
| `MAX_BOTTLE_LINES`    | `9`        | 丢瓶子时允许的最大文本行数                        |
| `MAX_BOTTLE_WORD`     | `1200`     | 丢瓶子时允许的最大字符数量                        |
| `EMBEDDED_HELP`       | `true`     | 丢瓶子未填写任何内容时，是否回复指令帮助          |
| `DEFAULT_NICKNAME`    | `未知昵称` | 获取昵称失败时评论区用户的默认称呼                |
| `BOTTLE_MSG_SPLIT`    | `true`     | 瓶子内容与评论区是否分为两条消息发送              |
| `MAX_BOTTLE_COMMENTS` | `3`        | 捡瓶子时最多展示的评论条数                        |
| `BOTTLE_MSG_UNAME`    | `true`     | 是否展示发送者昵称（官方 Bot 或追求速度时可关闭） |
| `BOTTLE_MSG_GNAME`    | `true`     | 是否展示来源群名称（同上）                        |

## 开关 / 权限 / 帮助

全部由真寻的插件元数据接管，无需额外配置：

- **分群开关**：进群默认**开启**。用 `switch` 指令或 WebUI 关闭后，本群内所有漂流瓶指令会被拦截并提示「该群未开启此功能」。
- **群权限等级**：`5`。
- **冷却**：`6` 秒（插件级，见下方「已知限制」）。
- **帮助**：`帮助 漂流瓶` 可查看详情页；插件在帮助菜单中归入「群内小游戏」分类。

## 数据存储

```
data/web_bottle/
├── bottle.db        # sqlite：approved（瓶子）/ comments（评论）/ user_up（点赞记录）
├── bottle_id.txt    # 瓶子 ID 自增计数
└── img/<瓶子ID>/    # 瓶子图片，统一转存为 webp
```

删除 `data/web_bottle/` 即可清空所有漂流瓶数据。

## 已知限制

- **冷却是按插件而非按指令**：真寻的 CD 限制作用于整个插件，因此上面 6 条指令共用同一个 6 秒冷却。
- **只支持 OneBot V11**，不兼容 QQ 官方适配器等。
- **不做图片清理**：瓶子被扔出后其图片会一直保留（原版靠「拒绝」时删图，本改版无审核流程，因此无删除时机）。
- 数据库操作使用同步 `sqlite3`，未做线程池隔离；低流量场景下无影响。
